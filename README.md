# Ashok Kumar Pitta — Portfolio Website

Personal portfolio website for Ashok Kumar Pitta, ML Engineer & Data Scientist based in Sheffield, UK.

🌐 **Live Site:** [portfolio-website-nine-omega-34.vercel.app](https://portfolio-website-nine-omega-34.vercel.app)

---

## About

A single-page portfolio built with vanilla HTML, CSS, and JavaScript. Features smooth scroll animations, a contact form via EmailJS, and a fully responsive layout.

---

## Sections

- **Hero** — intro, role, and key stats
- **About** — background, skills summary, and contact details
- **Skills** — full tech stack across ML, data engineering, cloud, and frameworks
- **Projects** — Finance RAG Framework and Web Traffic Forecasting Platform
- **Experience** — Python Developer / Data Scientist at Powered IT Solutions
- **Contact** — contact form (powered by EmailJS) and direct links

## Tech

- HTML5 / CSS3 / Vanilla JS
- [Syne](https://fonts.google.com/specimen/Syne) + [DM Sans](https://fonts.google.com/specimen/DM+Sans) + [DM Mono](https://fonts.google.com/specimen/DM+Mono) (Google Fonts)

- Deployed on [Vercel](https://vercel.com)
